Installation

Three steps and you are playing

1

Click the big download button and run the CrystalClient-install.exe file.

2

3

Launch it

The first launch downloads the game and the mod loader, then you sign in with your Microsoft account – or hit Play offline straight away.

System Windows 10 / 11 (64-bit)
Memory minimum 8 GB (16 GB recommended)
Free disk space ~1.5 GB including the game
Graphics Vulkan or OpenGL 3.2+
Java nothing to install – the bundled JDK 25 is used
⚠️ Windows may warn about an unknown publisher when you start the installer. This is normal SmartScreen behaviour for a freshly built, unsigned file: click More info, then Run anyway.

Crystal Client does not contain hacks, cheats or anything built to bypass the evaluation system, and it works in line with the rules and expectations of the game.
Do I need to install anything for Minecraft?

No. The installer uses the bundled JDK 25, and the launcher downloads the game files and the Fabric mods.

Does it work without an internet connection?

Yes. Once you have signed in, the Play offline button starts the game with your saved account – the game files and the mods are already on disk by then.

Do the mods get updated?

Yes. On startup the launcher asks Mojang's and Fabric's servers and downloads the current versions. The bundle is tied to a specific game version, not to your PC.

Where does the program install?

Into the %LOCALAPPDATA%\CrystalClient folder, under your user account – no admin rights needed, and it does not touch Program Files.
